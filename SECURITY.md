# Security policy — JDWIN-Public

## Scope

This repository (`JDWIN-Public`) is an **informational-only** public presence for the jdwin (جدوِن) product. It contains:

- `README.md` — product definition and overview  
- `assets/` — approved brand and illustrative images  

It does **not** contain runnable application code, configuration, or secrets.

## Reporting vulnerabilities

If you believe you have found a security issue in the **live jdwin product** at [jdwinai.com](https://jdwinai.com), please report it through the official support channel:

**[https://jdwinai.com/en/support](https://jdwinai.com/en/support)**

Do **not** open public GitHub issues for undisclosed security findings.

## What not to submit here

Please do **not** post the following to this repository’s issues or pull requests:

- API keys, tokens, passwords, or webhook secrets  
- Private URLs, internal admin paths, or infrastructure details  
- Source code dumps or reverse-engineered scoring logic  
- Personal data or production customer information  

This repository is not monitored for operational security incidents.

## Repository integrity

Maintainers will reject any contribution that adds:

- Executable code or dependency manifests  
- Environment files (`.env`, credentials JSON, etc.)  
- Internal documentation not approved for public release  

The purpose of this repo is **definition and illustration only**.
